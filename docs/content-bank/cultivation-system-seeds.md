# 修行系统素材

更新时间：2026-05-08

## 核心抽象

本项目不把修行做成单一经验条。修行应由几类东西共同推动：

- `qi`：可积累的气，支持吐纳、日课、突破。
- `insight`：理解、见闻、辨认能力，支持玉简、药性、功法、瓶颈。
- `lifespan`：时间压力，支撑闭关、失败、飞升结算。
- `wounds`：短中期代价，影响斗法、突破和外出。
- `heartDemon`：后续快速修行、冒进、杀夺的代价。
- `pillToxin`：后续服丹与炼丹失败的代价。
- `karma`：后续关系、劫数、机缘和结算的长尾。

## 五行作为“相位”

参考五行资料时，优先理解为动态阶段，而不是固定物质。游戏转化如下：

| 相 | 游戏含义 | 季节 | 地点/行动 | 风险 |
| --- | --- | --- | --- | --- |
| 木 | 生发、药性、成长 | 春 | 采药、药圃、启蒙 | 过盛则散乱 |
| 火 | 爆发、术法、心神 | 夏 | 突破、斗法、炼炉 | 过盛则心魔 |
| 土 | 承载、调和、转化 | 四季交界 | 调息、炼丹、居处 | 过重则迟滞 |
| 金 | 收束、规矩、锋锐 | 秋 | 外门、斗法、账本 | 过刚则伤 |
| 水 | 收藏、寿元、潜修 | 冬 | 闭关、溪谷、夜露 | 过寒则滞 |

## 灵根素材

灵根不在开局硬选，可以先隐藏为数据，随着事件被感知。

| 类型 | 初期表现 | 机械效果 | 文案提示 |
| --- | --- | --- | --- |
| 五行杂根 | 慢而稳，适合普通开局 | qi 获取低，适应广 | “气行得慢，但不偏。” |
| 四灵根 | 稍有偏向 | 少量相性加成 | “某一相少滞。” |
| 三灵根 | 路线逐渐明显 | 适合功法选择 | “三相轮转，已有轻重。” |
| 双灵根 | 效率高但偏科 | 对应相位强，逆相弱 | “两股气先后入脉。” |
| 天灵根 | 快速但事件压力高 | qi 高，心魔/宗门注意高 | “气来得太快。” |
| 异灵根 | 风雷冰等变体 | 特殊事件和术法 | “不在五行正序中。” |

## 功法数据轴

后续功法不只加数字，应至少有这些属性：

| 字段 | 示例 | 影响 |
| --- | --- | --- |
| `phase` | 木/火/土/金/水/无相 | 地点、季节、灵根相性 |
| `tempo` | 稳、急、缓、险 | tick 收益和风险 |
| `purity` | 清、杂、偏、浊 | 突破稳定度 |
| `cost` | 精元、寿元、草药、钱、人情 | 路线差异 |
| `risk` | 心魔、伤、丹毒、因果 | 长线后果 |
| `routeQuality` | 清修、丹道、斗法、坊市 | 道途形成 |

原创功法名先用朴素功能名：

- 小吐纳法：低收益、低风险。
- 稳息诀：调息效率和突破稳定。
- 引木诀：春季/药坡加成。
- 伏火诀：夏季/炼炉加成，心魔风险。
- 守土诀：低收益但减伤、减丹毒。
- 听水诀：冬季/闭关加成，外出收益低。

## 突破事件结构

突破不应是一个按钮直接成功。建议结构：

1. 准备状态：资源、功法、地点、季节、关系辅助。
2. 预兆日志：短句提示风险，不剧透结果。
3. 选择：稳固 / 冒进 / 借丹 / 求人护法 / 放弃。
4. 结算：成功、半成、失败、留下瓶颈。
5. 后续：伤、寿元、心魔、丹毒、关系变化或新地点。

示例：

```text
夜半，气行至关。
炉灰不动。

选择：
- 稳住周天：消耗时间，降低失败。
- 借丹强行：消耗丹药，增加丹毒。
- 收功：保留部分进度，不添伤。
```

## 当前已落地

- `吐纳 -> 日课吐纳 -> 三日闭关`：用更长耗时和更高精元成本减少机械点击，继续写入 `quiet_cultivation`。
- `外门短差 -> 外门供给`：用 `sect_trace` 和短差次数解锁轻量供给，先表达宗门影子，不提前展开完整宗门经济。
- `炼气三层 -> 筑基关口`：筑基作为第一道大瓶颈，读取稳固次数、清修、灵根相性、丹毒、伤势、外门护法和坊市借丹；成功进入筑基一层，失败添重伤、损寿元并留下 `foundation_scar`。

## 待筛选种子

- 筑基“收功”不应只是取消按钮：可设计成保留部分稳固、消耗时间、失去过期机缘，或让护法/借丹关系不再完全退回。
- 筑基失败长期后果可以从三条线展开：骨伤影响闭关效率、坊市债影响价格/事件、外门护法影响宗门名册与规矩。
- 后续宗门任务应读取 `sect_trace`、`foundation_guardian`、`foundation_scar`、`market_debt`，让筑基前的选择在筑基后仍被世界记住。

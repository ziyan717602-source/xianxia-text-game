# 世界与事件素材

更新时间：2026-05-08

## 事件设计字段

后续事件建议至少准备这些字段：

| 字段 | 用途 |
| --- | --- |
| `id` | 稳定事件编号 |
| `locationIds` | 可能出现的地点 |
| `season` / `solarTerm` | 季节或节气调制 |
| `weight` | 基础权重 |
| `conditions` | 境界、资源、flag、relationship、quality |
| `choices` | 选择文本 |
| `effects` | 资源、flag/tag/quality、关系、地点状态 |
| `expiresAfter` | 机缘或人物是否会过期 |
| `logTone` | 旁观记录、坊市传闻、内观记录、账本记录 |

## 地点扩展素材

| 地点 | 核心动作 | 事件倾向 | 状态字段 |
| --- | --- | --- | --- |
| 居处 | 枯坐、吐纳、调息、日课、闭关 | 残卷、入静、旧物、来访 | `qiDensity`、`quiet`、`hasStove` |
| 山路 | 采药、巡山、避让、追踪 | 伤者、兽痕、药香、遗物 | `danger`、`herbRichness`、`patrol` |
| 坊市 | 交易、听闻、赊欠、出售 | 涨价、传闻、掌柜、散修 | `priceModifier`、`rumorHeat`、`credit` |
| 溪谷 | 取水、夜露、潜修 | 水相、寒气、足迹 | `waterQi`、`slippery` |
| 废观 | 清扫、探查、借宿 | 旧符、石碑、禁忌 | `ruinDepth`、`taboo` |
| 外门 | 杂役、领规、听课、交差 | 规矩、贡献、同门 | `sectPressure`、`contribution` |
| 药坡 | 辨药、采种、护苗 | 药性、虫害、抢采 | `herbQuality`、`seasonalBloom` |
| 渡口 | 远行、听客、雇船 | 外地消息、失踪、税费 | `travelAccess`、`fare` |

## NPC 原型

| 原型 | 身份 | 关系标签 | 可触发后果 |
| --- | --- | --- | --- |
| 受伤散修 | 山路遇见的低阶修士 | `受你援手`、`旁观`、`被你搜掠` | 回访、报恩、结怨、坊市传言 |
| 坊市掌柜 | 草药和杂货交易者 | `赊账`、`熟客`、`压价` | 价格变化、假货、私下消息 |
| 外门书吏 | 管贡献和名册 | `记名`、`拖欠`、`照拂` | 外门任务、规矩惩罚 |
| 失意同门 | 突破失败者 | `借丹`、`见证失败` | 心魔提示、丹毒警示 |
| 山居老人 | 非修士邻里 | `旧识`、`托付` | 寿元感、俗世牵挂 |
| 巡山弟子 | 宗门边界人员 | `盘问`、`放行`、`冲突` | 外门影子、宗门规矩 |
| 游方讲经人 | 路过坊市的修士 | `听讲`、`质疑` | 功法理解、道途倾向 |

## 第一批事件种子

| 事件 | 条件 | 选择 | 状态后果 |
| --- | --- | --- | --- |
| 山路旧债 | `wounded_cultivator.favors > 0` | 接受谢礼 / 推辞 / 问路 | `relationship.favors` 减少，获得钱/见闻/地点线索 |
| 山路冷眼 | `wounded_cultivator.grudges > 0` | 避开 / 交涉 / 斗法 | 伤、仇怨、因果、斗法倾向 |
| 雨后药芽 | 春季或雨水段，山路 | 采药 / 留种 / 标记地点 | 草药、药坡线索、丹道倾向 |
| 坊市涨价 | 坊市，秋冬或传闻热 | 买入 / 观望 / 赊账 | 钱、信用、掌柜关系 |
| 外门规矩 | 听到宗门传闻后 | 记下 / 嗤笑 / 打听 | 外门线索、规矩 tag、坊市牵连 |
| 外门书吏 | 外门、炼气、已听规矩 | 登记 / 问短差 / 退下 | `outer_gate_clerk` 关系、`sect_trace` tag、短差解锁 |
| 冬至静坐 | 冬至段，居处 | 闭门 / 出行 / 服丹 | qi、寿元显示、心魔/丹毒 |
| 同门失败 | 炼气后，坊市或外门 | 旁观 / 送药 / 问因 | 突破风险提示、关系、丹毒知识 |
| 药性不合 | 首次炼丹前 | 细辨 / 试服 / 出售 | 药性知识、丹毒、钱 |

## 世界日志句式

保持冷静、短句、可复读：

```text
春分过后，山路泥少。
坊市照开，草药价低了一成。
某散修三日未至。
你在檐下坐满一日，气未散。
冬至夜长，炉灰微白。
```

近日摘要可以是结构化句子：

```text
近十日：居处日课六次，山路两行，坊市一次。
真气增九，草药余三。
受伤散修仍未回访。
```

## 当前已落地

- 外门规矩：听闻后写入 `heard_outer_gate_rules`、`sect_trace` tag/quality。
- 外门书吏：登记或问短差会写入 `outer_gate_clerk` 关系，开启外门短差。
- 外门短差/供给：用 `sect_trace` 和 `completed_sect_errand` 渐进解锁，先作为宗门影子，不做完整宗门身份。
- 外门点卯/巡值：登记后可点卯，点卯后可领巡值，写入 `sect_discipline`、`sect_contribution` 和近日摘要。
- 外门失期/巡值回报：登记后闭关不点卯会触发失期事件；巡值后可照规交差、夹带草药或问边界路。

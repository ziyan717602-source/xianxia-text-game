# 内容素材库

更新时间：2026-05-07

本目录保存后续开发可直接参考的原创内容素材和系统资料。它不是剧情正文库，而是“机制化素材库”：每个条目都应能转化为数据、事件、日志、地点、NPC 或测试用例。

## 文件

- `world-event-seeds.md`：地点、节气、NPC、关系标签、事件种子、世界日志。
- `cultivation-system-seeds.md`：灵根、五行、功法、突破、道途和劫数。
- `alchemy-herb-seeds.md`：虚构草药、药性轴、丹方结构和丹毒风险。

## 使用规则

- 写事件前先确认它会留下什么状态：`flag`、`tag`、`quality`、`relationship` 或地点变化。
- 写地点前先确认它改变什么：可用行动、事件权重、危险度、价格、灵气、季节修正。
- 写丹药前先确认它的代价：丹毒、心魔、伤、寿元、药材稀缺或突破风险。
- 文案保持短、淡、可复读。不要把一次按钮点击写成长段小说。
- 所有命名保持原创。可以使用通用概念，如灵气、丹毒、筑基、天劫；不要复用现有作品的专名。

## 来源边界

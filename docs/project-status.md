# 项目状态梳理

更新时间：2026-05-07

## 当前阶段

阶段 1：最小可玩原型骨架已建立，但仍未完成“有手感的第一阶段修行体验”。

## 已开发

### 工程与环境

- Vite + React + TypeScript 工程骨架。
- npm lockfile 和 `.npmrc`，支持工作电脑与个人 PC 双机开发。
- `npm ci`、`npm test`、`npm run build` 可在当前工作机通过。
- GitHub 远端 `origin/main` 已同步。

### 核心逻辑

- `GameState` 类型：资源、境界、灵根、时间、地点、关系、选择状态、活动事件、seed。
- 初始状态工厂 `createInitialState`。
- Tick 引擎：tick 推进、精元恢复、寿元扣减。
- 行动系统：枯坐、吐纳、采药、巡山、调息。
- 解锁系统：吐纳、辨药、残卷标记、日课吐纳标记。
- 地点模型：居处、山路、坊市。
- 选择状态账本：flags、tags、qualities。
- 关系账本：新增、读取、更新关系。
- 事件系统：权重抽取、事件选择、事件弹窗。
- 轻量斗法：避让、交涉、斗法。
- 存档：localStorage 序列化/反序列化、版本迁移入口。

### UI

- React 主界面。
- 状态/行动/日志三栏布局。
- 保存、重置。
- 事件弹窗。
- 自动保存与 tick loop hook。

### 测试

- 9 个测试文件。
- 34 个测试用例。
- 覆盖状态、tick、行动、解锁、地点、关系、事件、斗法、存档。

- 出身系统：山居采药人、乡塾读书人、坊市杂役、外门童子、游方散人；出身只影响早期资源、地点、行动和倾向，不锁死后续道途。
- 修行账本：隐藏灵根、五行相性、主相、已知功法和当前功法。
- 灵根/功法行动：炼气后可 `内视灵根`，辨明灵根后可 `按相修订`，将小吐纳法调整为相性功法。
- 五行相性：已接入吐纳/日课收益修正，读取灵根相性、当前功法、季节和地点。
- 炼丹账本：已知丹方、炼制次数、服丹次数。
- 丹药药性：`小聚气丸`、`稳息散`、`清躁丸`、`通脉丸`、`固基丹`、`聚灵丸`、`暖炉丹`、`夜坐丸` 已有寒凉/平涩/寒苦、五行、升浮/沉降、药材主佐字段。
- 炼丹行动：炼气后通过多次 `辨药` 解锁 `辨小丹方`，学方后可 `炼小聚气丸`，有成功率、季节/丹道/相性修正和失败药渣。筑基后可辨通脉方/固基方/聚灵方。炼气后可辨暖炉方，筑基后可辨夜坐方。
- 服丹与丹毒：`服小聚气丸` 增加真气并累积丹毒；丹毒达到 10/30/60 段后有阶段标签，已先影响调息恢复。
- 稳息散路径：遭遇关口、伤势或丹毒后可辨 `稳息方`，炼成后服用会略降丹毒、压慢真气，并给下一次冲关护持。
- 清躁丸路径：重丹毒或丹毒入脉后可辨 `清躁方`，炼成后服用会明显降低丹毒、压伤势和冒进倾向，但损精元。
- 丹毒入脉事件：丹毒达到 60 后在居处触发，玩家可静坐逼毒、翻检清躁方或强行压下，并留下 flags/qualities 后果。
- 突破账本：记录关口稳固、冲关次数、成功、失败和最近目标。
- 突破规则：15 条突破规则覆盖所有境界——炼气二至九层（递增资源需求，递减基础成功率 62%→20%）、筑基（大关口，需护法或借丹）、金丹（筑基三层后，雷劫前兆）、元婴（金丹后，出窍神游）、化神（元婴后，神识与天地相融）、合体（肉身与天地合一）、大乘（万道归一）、渡劫（天劫降临）。
- 失败后果：小境界冲关失败会添伤、损寿元并记录 `reckless_breakthrough` 倾向；筑基失败会添更重伤势、损更多寿元并留下 `foundation_scar`；半成不会进阶，但会增加关口稳固。筑基骨伤、借丹账和护法账已有第一批后续事件。
- 坊市/外门行动：小买卖、听闻、外门杂务、听课、领外门短差、领外门供给、外门点卯、领外门巡值。

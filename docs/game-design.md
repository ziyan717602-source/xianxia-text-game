# 游戏设计草案

更新时间：2026-05-06

## 核心体验

玩家从寻常人世开始，不是天命之子，也不是灾厄孤儿。开局可以普通、安稳、甚至略显平淡；修行本身会逐渐引出资源、瓶颈、代价、因果和寿元压力。前期像日课，中期像经营，后期像抉择驱动的长线修真。每一次系统解锁都应改变玩家对世界的理解。

## 核心循环

1. 行动：吐纳、采药、读书、巡山、交易、闭关。
2. 产出：灵气、草药、木柴、银钱、见闻、因果、心魔。
3. 转化：炼丹、布阵、温养法器、突破瓶颈、换取功法。
4. 风险：走火入魔、药毒积累、秘境伤势、天劫、宗门纷争。
5. 解锁：新地点、新系统、新资源、新叙事层。

## 资源池

| 资源 | 用途 | 设计风险 |
| --- | --- | --- |
| 灵气 | 修炼、突破、驱动阵法 | 不能只变成线性货币 |
| 体力 | 限制早期手动行动 | 等待过长会无聊 |
| 草药 | 炼丹、交易、疗伤 | 需要品质和配方变化 |
| 木柴 | 早期生存、火候、阵基 | 中后期应逐步弱化 |
| 银钱 | 坊市交易、雇佣、购置 | 不应压过修行主题 |
| 灵石 | 中后期硬通货 | 产出要和探索/宗门绑定 |
| 丹毒 | 服丹代价 | 提醒玩家不要无限堆丹 |
| 心魔 | 快速修行代价、剧情分支 | 需要可管理而非纯惩罚 |
| 因果 | 选择后果、劫数权重 | 适合长线叙事 |

## 境界节奏

- 凡人：普通生活、识字或习艺、发现灵气。
- 炼气：稳定修行，解锁灵田、草药、低阶术法。
- 筑基：第一次重大瓶颈，要求资源、心境和机缘，而非单一数值。
- 金丹：进入宗门、秘境、法器、因果选择。
- 元婴及以后：世界规模扩大，加入洞府、弟子、劫数和飞升路线。

## 渐进揭示

- 开局只显示可理解的少数动作，避免一次性暴露完整系统。
- 新系统由事件或资源阈值解锁，例如“残卷发热”后出现打坐，“炉火稳定”后出现炼丹。
- 文案应短、克制、可复读，避免长段小说压住操作节奏。
- 开局路线只改变早期手感和解锁顺序，不锁死职业。玩家经常做什么，什么道途才逐渐显形。

## 道途形成

不要让玩家在开局选择“剑修/丹修/符修”等固定职业。道途应由行为统计、事件选择和资源结构共同形成：

- 常采药、辨药、炼丹，丹道自然加深。
- 常巡山、斗法、磨剑，剑路自然显现。
- 常闭关、压境、避事，清修路线更稳。
- 常交易、结人情、接委托，坊市和因果牵连更深。
- 常冒进、借丹、走偏法，心魔和劫数权重上升。

选择应时刻存在，但不是永远等玩家。有些人物会离开，有些机缘会过季，有些瓶颈拖久了会变成另一个问题。

## 鲜活世界

世界不围着玩家转，但要持续运转：

- 季节影响草药、雨水、闭关效率、物价和某些事件权重。
- 坊市有短期商队、涨跌价、传闻、借贷和赊欠。
- NPC 以关系痕迹存在：债、人情、仇、同门、旧识、交易对象。
- 事件受地点、境界、名声、因果、道途倾向和过去选择影响，而不是纯随机奖励/惩罚。
- 日志用淡然旁观的口吻记录世界变化，不替玩家评价。

## 反坐牢积累

重复积累是修行题材的根，但不能长期要求机械点击。同一行为应逐步升格：

```text
吐纳 -> 日课 -> 闭关 -> 聚气阵 -> 洞府供养
采药 -> 识药 -> 种药 -> 药圃 -> 丹房消耗
交易 -> 赊账 -> 固定商路 -> 坊市名声 -> 宗门供给
```

手动阶段用于理解系统；稳定后必须提供自动化、批量化、离线收益或新的决策层。

## 最小可玩版本

- 单页面文字 UI。
- 一个 tick 循环和离线收益。
- 资源：气、体力、药、钱、见闻。
- 动作：吐纳、采药、读书、巡山、休息。
- 开局路线：山居、乡塾、坊市、外门、游方中的若干路线，影响起始资源和早期事件。
- 解锁：第一门吐纳法、药材辨识、简易炼丹、坊市传闻。
- 存档：localStorage，带版本号和重置入口。
- 测试：资源 tick、解锁条件、存档读写。

# 游戏设计草案

更新时间：2026-05-09

## 核心体验

玩家从寻常人世开始，不是天命之子，也不是灾厄孤儿。开局可以普通、安稳、甚至略显平淡；修行本身会逐渐引出资源、瓶颈、代价、因果和寿元压力。前期像日课，中期像经营，后期像抉择驱动的长线修真。每一次系统解锁都应改变玩家对世界的理解。

## 核心循环

1. 行动：枯坐、吐纳、采药、辨药、巡山、调息、交易、闭关。
2. 产出：气、药、钱、见闻、因果、心魔、伤、寿元压力。
3. 转化：炼丹、布阵、温养法器、突破瓶颈、换取功法。
4. 风险：走火入魔、药毒积累、秘境伤势、天劫、宗门纷争。
5. 解锁：新地点、新系统、新资源、新叙事层。

## 资源池

| 资源 | 用途 | 设计风险 |
| --- | --- | --- |
| 灵气 | 修炼、突破、驱动阵法 | 不能只变成线性货币 |
| 精元 | 限制早期手动行动、驱动阵法与突破 | 等待过长会无聊 |
| 草药 | 炼丹、交易、疗伤（高阶修士以灵草为主） | 需要品质和配方变化 |
| 银钱 | 坊市交易、雇佣、购置 | 不应压过修行主题 |
| 丹毒 | 服丹代价 | 提醒玩家不要无限堆丹 |
| 心魔 | 快速修行代价、剧情分支 | 八种心魔由行为倾向触发，可直面/压制/无视 |
| 见闻/神识 | 悟性、事件权重、秘境探索深度 | 不宜过快积累 |
| 因果 | 选择后果、劫数权重 | 适合长线叙事 |
| 寿元 | 时间压力、闭关成本、失败代价、结算 | 不宜早期过强压迫 |
| 伤 | 斗法、秘境、突破失败后的短中期代价 | 不能只当血条 |

## 境界节奏

- 凡人：普通生活、识字或习艺、发现灵气。寿元 60 年。
- 炼气：稳定修行，解锁灵田、草药、低阶术法。9 层递进，寿元 100 年。
- 筑基：第一次重大瓶颈，要求资源、心境和机缘，而非单一数值。3 层，寿元 200 年。
- 金丹：进入宗门核心、秘境深处、法器、因果选择。金丹雷劫、丹成异象。寿元 500 年。
- 元婴：出窍神游，世界规模扩大。洞府、弟子、天阁悟道。寿元 1000 年。
- 化神：神识与天地相融，开辟化神之路。古战场、灵山初探。寿元 2000 年。
- 合体：肉身与天地合一，虚空之力。虚空裂隙、合体虚空秘境。寿元 5000 年。
- 大乘：万道归一，大乘悟道。灵山闭关、天道启示。寿元 10000 年。
- 渡劫：天劫降临，飞升前的最后考验。渡劫台、天雷淬体。寿元 50000 年。

功法按品级分层：凡级→黄级→玄级→地级→天级，高阶功法需高境界才能修习。
丹药按境界分阶：炼气期丹药→筑基丹→金丹期丹药→元婴期丹药→化神丹→合体丹→大乘丹→渡劫丹。
丹药品级：凡品→黄品→玄品→地品→天品，品级越高效果越强但炼制难度越大。
地图按境界递进：凡人区域→宗门外围→核心峰→雷峰→古战场→虚空裂隙→灵山→渡劫台。

## 底层修仙语法

第一版不需要向玩家展示完整复杂表，但数据层要预留：

- 灵根：影响气的获取、相性、瓶颈和功法理解。开局可粗略表达，不做职业锁死。
- 五行：影响地点灵气、药材、丹药、术法、阵法和突破条件。
- 功法相性：同一功法对不同灵根、地点、季节、行为习惯有不同收益和代价。
- 丹药药性：丹药不只是加资源，应有药性、丹毒、适用境界和相性。
- 地点灵气：山、坊市、宗门、洞府、秘境的行动和事件权重不同。

## 渐进揭示

- 开局只显示可理解的少数动作，避免一次性暴露完整系统。
- 新系统由事件或资源阈值解锁，例如“残卷发热”后出现打坐，“炉火稳定”后出现炼丹。
- 文案应短、克制、可复读，避免长段小说压住操作节奏。
- 开局路线只改变早期手感和解锁顺序，不锁死职业。玩家经常做什么，什么道途才逐渐显形。

## 道途形成

不要让玩家在开局选择“剑修/丹修/符修”等固定职业。道途应由行为统计、事件选择和资源结构共同形成：

- 常采药、辨药、炼丹，丹道自然加深。
- 常巡山、斗法、磨剑，剑路自然显现。
- 常闭关、压境、避事，清修路线更稳。
- 常交易、结人情、接委托，坊市和因果牵连更深。
- 常冒进、借丹、走偏法，心魔和劫数权重上升。

选择应时刻存在，但不是永远等玩家。有些人物会离开，有些机缘会过季，有些瓶颈拖久了会变成另一个问题。

## 鲜活世界

世界不围着玩家转，但要持续运转：

- 季节影响草药、雨水、闭关效率、物价和某些事件权重。
- 坊市有短期商队、涨跌价、传闻、借贷和赊欠。
- NPC 以关系痕迹存在：债、人情、仇、同门、旧识、交易对象。
- 事件受地点、境界、名声、因果、道途倾向和过去选择影响，而不是纯随机奖励/惩罚。
- 日志用淡然旁观的口吻记录世界变化，不替玩家评价。

最小实现需要两个账本：

- 地点账本：地点 id、名称、可用行动、基础事件权重、灵气/危险/物价、季节修正。
- 关系账本：对象 id、身份、关系标签、最近交互、债/人情/仇怨、存活/离开/坐化状态。

## 斗法与风险事件

斗法占比低到中等，作为风险检验出现：

- 斗法事件优先发生在巡山、秘境、宗门争端和高因果状态下。
- 结算读取气、术法、法器、伤、心魔、地点危险度和对方境界。
- 玩家应常有避战、交涉、让利、求援或硬斗选择。
- 失败改变后续局面，例如伤、失物、欠债、结仇、错过机缘，而不是简单重开。

## 反坐牢积累

重复积累是修行题材的根，但不能长期要求机械点击。同一行为应逐步升格：

```text
吐纳 -> 日课 -> 闭关 -> 聚气阵 -> 洞府供养
采药 -> 识药 -> 种药 -> 药圃 -> 丹房消耗
交易 -> 赊账 -> 固定商路 -> 坊市名声 -> 宗门供给
```

手动阶段用于理解系统；稳定后必须提供自动化、批量化、离线收益或新的决策层。

## 最小可玩版本

- 单页面文字 UI。
- 一个 tick 循环和离线收益。
- 资源：气、精元、药、钱、见闻/神识、寿元、伤。
- 动作：枯坐、吐纳、采药、辨药、巡山、调息。
- 开局路线：山居、乡塾、坊市、外门、游方中的若干路线，影响起始资源和早期事件。
- 解锁：第一门吐纳法、药材辨识、简易炼丹、坊市传闻。
- 地点：居处、山路、坊市三个最小地点。
- 账本：地点账本、关系账本、选择 flag/tag/quality。
- 风险：第一批轻量斗法/避战/交涉事件。
- 存档：localStorage，带版本号和重置入口。
- 测试：资源 tick、解锁条件、地点事件权重、关系账本、存档读写。

## 宗门系统

宗门是修行社会的基本结构，从外门到长老逐级递进：

- 外门弟子：登记后获得宗门庇护，需完成杂务、点卯、巡值；违反规矩会受惩罚。
- 内门弟子：筑基后准入，接受宗门任务、获取供给折扣和高级地点权限。
- 核心弟子：金丹以上，参与宗门决策、分配资源和秘境名额。
- 长老：高境界担当，负责宗门运转和传承。
- 宗门规矩：贡献值衡量贡献，规矩值衡量违纪；两者影响供给、任务和突破支援。
- 宗门惩罚：失期、旷卯、违令会扣除规矩值，严重者驱逐。

## 洞府与阵法

洞府是修士的私人修炼空间，可升格和布阵：

- 洞府等级：简陋洞府 → 灵气洞府 → 阵法洞府，每级提升灵气密度和自动产出。
- 阵法系统：聚灵阵（提升灵气吸收）→ 护法阵（突破护持）→ 洞天阵（高级洞府），阵法可安装和升级。
- 自动收入：洞府每日自动产出灵气、药材等资源，升格后产出增加。
- 阵法加成：突破时读取洞府阵法等级，提供额外成功率和护持效果。

## 弟子/杂役

修士可招募从属分担劳动：

- 招募：杂役（低阶劳力）和弟子（有潜力修士），消耗银钱和贡献。
- 分配任务：采药、巡值等，从属自动执行并产出资源。
- 收入：每日收取从属劳动成果，高阶弟子产出更丰厚。
- 随境界提升：弟子品质和数量上限随修士境界增长。

## 秘境探索

秘境是高风险高回报的探险场所：

- 发现：特定境界、地点或事件触发秘境入口发现。
- 探索进度：每次行动推进探索进度，进度条显示当前进展。
- 半程事件：探索至一半时触发特殊事件，可能有遭遇、宝物或抉择。
- 完成收获：探索完成后获得灵气、草药、丹方、法器等奖励。
- 放弃与风险：中途放弃可获得部分收益但也有风险；飞升加成影响秘境奖励。
- 14 个秘境：从雾中药谷（炼气）到伏潮旧宫（渡劫），按境界递进。

## 飞升/重置

飞升是一轮修行的终点，也是新旅程的起点：

- 触发条件：元婴后真气满 200 可选择飞升。
- 四种选择：飞升（入上界）、留下（继续当前世界）、超脱轮回（保留 30% 品质并给予永久加成）、散灭（回归天地）。
- 终分计算：综合考量境界、道途、因果、关系、丹毒、伤势，给出修行评价。
- 超脱加成：下一轮获得永久品质加成，影响秘境奖励和突破成功率。
- 重置后保留：超脱选择的加成和部分解锁进度。

## 道途扩展

道途不止五种基本路线，而是十二条修仙大道：

- 五条基本道途：丹道、剑路、清修、商途、门中。
- 七条扩展道途：阵修（以阵入道）、符修（丹青入符）、器修（金石铸器）、兽修（驱兽御灵）、魔修（偏执入道）、禅修（明心见性）、鬼修（舍躯化魄）。
- 道途由行为倾向自然形成，不同道途读取不同品质权重。
- 道途影响功法理解、事件权重、突破条件和飞升评价。

## 心魔扩展

心魔系统从概念扩展为八种具体心魔：

- 冒进之魔：频繁冲关失败、借丹催进触发。
- 执念之魔：长期执着单一目标触发。
- 傲慢之魔：境界提升过快、看不起同辈触发。
- 药毒之魔：丹毒累积过高触发。
- 疑道之魔：突破多次失败触发。
- 贪欲之魔：富甲一方触发。
- 怯懦之魔：伤多而战力弱触发。
- 孤绝之魔：无人际且清修深触发。
- 应对方式：直面（消耗真气精元获神识）、压制（消耗寿元）、无视（进度满 100 时发作造成严重后果）。

## 炼气九层

炼气期从三层扩展为九层，提供更扎实的早期体验：

- 炼气一层至九层，每层需要递增的灵气资源和递减的基础成功率（62%→20%）。
- 筑基门槛从炼气三层提升至炼气九层，确保玩家充分体验早期系统。
- 每层突破均有对应的行动和事件，层层递进。
- 九层结构让炼气期成为完整的教学和探索阶段，而非匆匆路过的序章。

## 丹药品级

丹药按品级分层，品级越高效果越强：

- 凡品：基础丹药，炼气期常用，炼制难度低。
- 黄品：进阶丹药，筑基至金丹期，需要更高技艺。
- 玄品：珍品丹药，元婴至化神期，需珍稀药材。
- 地品：极品丹药，合体至大乘期，炼制成功率极低。
- 天品：传说丹药，渡劫期专属，需天材地宝和极高温火候。
- 品级影响：药效强度、丹毒累积、适用境界和炼制难度。

## 境界扩展

完整九大境界从凡人到渡劫：

- 凡人 → 炼气（9 层）→ 筑基（3 层）→ 金丹 → 元婴 → 化神 → 合体 → 大乘 → 渡劫。
- 每个境界有对应的突破规则、日课行动、专属地点和事件。
- 寿元随境界递增：60→100→200→500→1000→2000→5000→10000→50000 年。
- 高阶境界解锁对应秘境、功法、丹方和阵法。
- 金丹雷劫、元婴出窍、化神征兆、合体虚空、大乘悟道、渡劫天雷——每个大境界都有标志性事件。

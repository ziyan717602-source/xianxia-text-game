# 设计方向定稿

更新时间：2026-05-06

这份文档整理当前讨论形成的产品方向。后续设计、剧情、数值和 UI 都应优先服从这里的原则。

## 一句话

一款淡然旁观、逐步展开的文字修仙增量游戏。玩家从普通人世入道，在日课、机缘、瓶颈、寿元、因果和错过的选择中走到飞升。

## 基调

- 大道无情，仙路渺渺。
- 世界不评判玩家，只按规则结算。
- 旁白像史官或天道记录，少煽情，少主角光环。
- 不做“天崩开局”。玩家不是饥荒求生，而是在普通起点中开始修行。
- 文字可以直白，不必处处“仙气飘飘”。朴素命名更耐看。

示例口吻：

```text
第七年，春。

你筑基未成。
气散了三成，伤添一处。

隔日，坊市照开。
米价如旧。
```

## 玩家路线

不要早早选择固定职业。开局可以提供几条普通出身，但它们只影响早期资源、接触面和事件权重。

候选出身：

- 山居采药人：更早接触草药、药价、山路和丹道。
- 乡塾读书人：更早接触文字、残卷、悟性和功法理解。
- 坊市杂役：更早接触钱、人情、传闻和交易。
- 外门童子：更早接触宗门规矩、贡献和基础法门。
- 游方散人：更早接触路途、机缘和不稳定事件。

道途从行为中长出来：

- 炼丹多，丹道加深。
- 斗法多，剑路显形。
- 闭关多，清修更稳。
- 交易多，坊市牵连更深。
- 冒进多，心魔和劫数更重。

玩家应该时刻都有选择，但不是所有选择都会一直等着。错过本身也是修行的一部分。

## 世界鲜活

鲜活不靠大量剧情，而靠世界自行变化：

- 季节轮转：药材、雨雪、物价、闭关效率、秘境入口。
- 地点差异：坊市多交易，山路多遭遇，宗门多规矩，洞府多积累。
- 人物痕迹：债、人情、仇、同门、旧识、交易对象。
- 事件记忆：玩家曾救、欠、抢、拒绝、交易过的人，后续可以留下变化。
- 低频长期后果：十年后的一条路、一笔债、一场劫。

NPC 不需要像恋爱好感系统那样围绕玩家运作。一个散修可以常来卖药，某天不来；一个同门可以借钱后筑基失败；一个掌柜可以涨价而不解释。世界活着，但不讨好玩家。

## 反坐牢原则

重复积累必不可少，但长期机械点击不可接受。

每个积累动作都要有升格路径：

- 手动：玩家理解这个资源。
- 日课：玩家设定固定安排。
- 批量：玩家用时间换一段结果。
- 自动：阵法、洞府、雇佣、宗门供给接管低阶劳动。
- 升格：旧资源变成新系统的输入，而不是永远要求玩家点击。

如果一个动作已经被玩家执行十几次，设计上就要考虑是否该出现自动化、批量化或新的决策。

## 第一版终点

第一版做到飞升即可，不急着展开飞升之后。

飞升不是“全胜利”，而是阶段性结算：

- 玩家走过哪条路。
- 欠下多少因果。
- 损耗多少寿元。
- 经历哪些瓶颈和劫数。
- 最后选择飞升、留界、坐化或重开。

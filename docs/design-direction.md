# 设计方向定稿

更新时间：2026-05-09

这份文档整理当前讨论形成的产品方向。后续设计、剧情、数值和 UI 都应优先服从这里的原则。

## 一句话

一款淡然旁观、逐步展开的文字修仙增量游戏。玩家从普通人世入道，在日课、机缘、瓶颈、寿元、因果和错过的选择中走到飞升。

## 基调

- 大道无情，仙路渺渺。
- 世界不评判玩家，只按规则结算。
- 旁白像史官或天道记录，少煽情，少主角光环。
- 不做“天崩开局”。玩家不是饥荒求生，而是在普通起点中开始修行。
- 文字可以直白，不必处处“仙气飘飘”。朴素命名更耐看。
- 修仙感来自稳定系统语法：寿元、灵根、五行、功法相性、丹药药性、地点灵气、瓶颈、劫数。

示例口吻：

```text
第七年，春。

你筑基未成。
气散了三成，伤添一处。

隔日，坊市照开。
米价如旧。
```

## 玩家路线

不要早早选择固定职业。开局可以提供几条普通出身，但它们只影响早期资源、接触面和事件权重。

候选出身：

- 山居采药人：更早接触草药、药价、山路和丹道。
- 乡塾读书人：更早接触文字、残卷、悟性和功法理解。
- 坊市杂役：更早接触钱、人情、传闻和交易。
- 外门童子：更早接触宗门规矩、贡献和基础法门。
- 游方散人：更早接触路途、机缘和不稳定事件。
- 药铺学徒：丹道倾向深，药坡起步，更早接触辨药和炼丹。
- 战乱遗孤：斗法经历多，渡口起步，伤势和坚韧并存。
- 道观寄养：清修倾向强，废观起步，更早接触符文和静坐。

道途从行为中长出来：

- 炼丹多，丹道加深。
- 斗法多，剑路显形。
- 闭关多，清修更稳。
- 交易多，坊市牵连更深。
- 冒进多，心魔和劫数更重。

玩家应该时刻都有选择，但不是所有选择都会一直等着。错过本身也是修行的一部分。

## 世界鲜活

鲜活不靠大量剧情，而靠世界自行变化：

- 季节轮转：药材、雨雪、物价、闭关效率、秘境入口。
- 地点差异：坊市多交易，山路多遭遇，宗门多规矩，洞府多积累。
- 人物痕迹：债、人情、仇、同门、旧识、交易对象。
- 事件记忆：玩家曾救、欠、抢、拒绝、交易过的人，后续可以留下变化。
- 低频长期后果：十年后的一条路、一笔债、一场劫。
- 关系账本：重要 NPC 或群体至少记录身份、关系标签、最近交互、欠债/人情/仇怨、是否仍在当前世界。
- 地点账本：重要地点至少记录可用行动、事件权重、灵气/物价/危险度、季节影响。

NPC 不需要像恋爱好感系统那样围绕玩家运作。一个散修可以常来卖药，某天不来；一个同门可以借钱后筑基失败；一个掌柜可以涨价而不解释。世界活着，但不讨好玩家。

## 反坐牢原则

重复积累必不可少，但长期机械点击不可接受。

每个积累动作都要有升格路径：

- 手动：玩家理解这个资源。
- 日课：玩家设定固定安排。
- 批量：玩家用时间换一段结果。
- 自动：阵法、洞府、雇佣、宗门供给接管低阶劳动。
- 升格：旧资源变成新系统的输入，而不是永远要求玩家点击。

如果一个动作已经被玩家执行十几次，设计上就要考虑是否该出现自动化、批量化或新的决策。

## 文字选择

少做没有后果的选项。重要选择应写入状态账本：

- `flag`：一次性事实，例如“见过某散修”。
- `tag`：关系或身份，例如“欠坊市人情”“外门旧识”。
- `quality`：可累计倾向，例如“丹道倾向”“剑路倾向”“因果牵连”。

这些状态不一定立刻反馈，但后续应能影响价格、事件、NPC、突破、劫数或日志。

## 斗法定位

斗法不是主玩法，但需要作为修仙世界的风险检验。第一版只做轻量事件：

- 避战：损失机会，降低伤势风险。
- 交涉：读取名声、钱、人情或宗门身份。
- 斗法：读取气、术法、法器、伤、心魔、地点危险度。

不做动作战斗，不做堆攻击力的长期主循环。

## 第一版终点

第一版做到飞升即可，不急着展开飞升之后。

飞升不是“全胜利”，而是阶段性结算：

- 玩家走过哪条路。
- 欠下多少因果。
- 损耗多少寿元。
- 经历哪些瓶颈和劫数。
- 最后选择飞升、留界、坐化或重开。
